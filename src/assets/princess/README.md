# 공주 성장 그림

이 폴더에 그림 파일을 넣으면 코드 수정 없이 해당 단계에 바로 쓰입니다. 없는 단계는 앱에 내장된 효과(반짝이, 별, 무지개, 빛 날개, 금빛 후광)가 나옵니다.

| 파일 이름 | 쓰이는 곳 |
| --- | --- |
| `stage-2.webp` … `stage-6.webp` | 공주 **뒤**에 그려지는 그림 (후광, 날개, 빛, 무지개 등) |
| `stage-2-front.webp` … `stage-6-front.webp` | 공주 **앞**에 그려지는 그림 (반짝이, 떠 있는 왕관, 요정 친구 등) |
| `stage-1-body.webp` … `stage-6-body.webp` | 공주 **몸** 그림 자체를 바꿈 (선택) |

단계: 1 아기 공주 · 2 꼬마 공주 · 3 별빛 공주 · 4 무지개 공주 · 5 마법 공주 · 6 여왕님

## 등록된 장식

아래 그림은 모두 640×800 픽셀의 투명 배경 WebP이며, 기존 캐릭터 뒤에 표시됩니다.

![기존 공주와 드레스를 겹친 2~6단계 장식 미리보기](../../../art/princess-growth-preview.webp)

| 파일 | 장식 |
| --- | --- |
| `stage-2.webp` | 분홍빛 후광, 작은 반짝이와 꽃 장식 |
| `stage-3.webp` | 금빛 별 고리와 별빛 |
| `stage-4.webp` | 파스텔 무지개와 작은 구름 |
| `stage-5.webp` | 연보라 요정 날개와 발밑 마법진 |
| `stage-6.webp` | 금빛 햇살 후광, 반짝이와 발밑 구름 |

GPT 이미지 생성에 사용한 요청 문구는 [`art/princess-growth.json`](../../../art/princess-growth.json)에 보관합니다.

## 그림 규격

- 크기 640×800 픽셀(또는 320×400), 세로 4:5 비율, **배경 투명**, WebP 또는 PNG.
- 공주는 캔버스 가운데에 서 있습니다: 머리 꼭대기가 위에서 약 2%, 발끝이 아래에서 약 2%, 몸 너비는 가운데 60% 정도.
- 뒤/앞 그림은 공주 얼굴과 몸통을 가리지 않게, 가장자리와 머리 위·발밑에 그립니다. 옷·모자·날개 아이템이 그 위에 겹쳐집니다.
- 몸 그림(`-body`)을 바꿀 때는 `public/assets/avatar-base-generated.webp`와 **같은 자세·같은 위치·같은 크기**여야 옷과 왕관이 맞습니다. 어렵다면 몸은 그대로 두고 뒤/앞 그림만 넣는 것을 권합니다.

## 그림 생성 요청 예시

> 첨부한 캐릭터(avatar-base-generated)와 같은 그림체로, 640×800 투명 배경 PNG를 만들어 줘.
> 캐릭터는 그리지 말고, 캐릭터 **뒤에 놓일 장식만** 그려 줘. 가운데(얼굴·몸통 자리)는 비워 두고 가장자리에 그려 줘.
> - stage-2: 은은한 분홍빛 후광과 작은 반짝이 몇 개
> - stage-3: 머리 주위를 도는 별 고리와 별빛
> - stage-4: 등 뒤에 크게 뜬 파스텔 무지개와 작은 구름
> - stage-5: 등 뒤로 펼쳐진 빛나는 연보라 요정 날개와 발밑 마법진
> - stage-6: 금빛 햇살 후광, 흩날리는 금빛 반짝이, 발밑의 금빛 구름
