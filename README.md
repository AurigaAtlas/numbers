# 숫자 놀이터

5살 아이가 iPad에서 1부터 10까지 숫자를 익힐 수 있도록 만든 React 숫자게임입니다.

## 기능

- 숫자 찾기: 음성을 듣고 맞는 숫자 카드를 선택합니다.
- 몇 개일까: 그림을 하나씩 눌러 세고 숫자를 고릅니다.
- 차례차례: 작은 숫자부터 순서대로 누릅니다.
- 카드 기억하기: 같은 숫자 카드 짝을 찾습니다.
- 어느 쪽이 많을까: 많은 쪽/적은 쪽(높은 단계에서는 큰 수/작은 수)을 고릅니다.
- 빈칸 채우기: 숫자 줄에서 빠진 숫자를 찾습니다. 거꾸로 세기, 2씩 뛰어 세기도 나옵니다.
- 더하기 빼기: 그림으로 덧셈과 뺄셈을 합니다.
- 풍선 터뜨리기: 날아오르는 풍선 중 목표 숫자를 찾아 터뜨립니다.
- 한글 놀이 (홈 화면 위쪽 탭에서 숫자/한글 전환)
  - 소리 듣고 찾기: 소리를 듣고 자음·모음·글자·낱말을 고릅니다.
  - 그림 글자: 그림을 보고 첫 자음, 첫 글자, 낱말을 찾습니다.
  - 글자 만들기: 자음과 모음을 합친 글자를 고릅니다 (ㄱ + ㅏ = 가).
  - 따라 쓰기: 손가락으로 글자를 따라 씁니다. 글자 선을 얼마나 따라갔는지 확인합니다.
- 주사위 마을 (홈 화면의 주사위 마을 배너)
  - 주사위 두 개를 굴려 점이 모두 몇 개인지 맞히면, 그 수만큼 "하나, 둘, 셋" 세며 칸을 이동합니다.
  - 마을 터("사과 마을" 등)에 도착하면 첫 글자와 자음을 알려주고, 모은 코인으로 집을 살 수 있습니다.
  - 내 집에 다시 도착하면 집세를 받고, 지붕 색·꽃밭·울타리·강아지 등으로 꾸미거나 2층 집 → 성으로 키웁니다.
  - 숫자 카드·글자 카드·학교 칸에서는 퀴즈를, 놀이터·선물 상자 칸에서는 보너스를 받습니다. 출발점을 지나면 용돈을 받습니다.
  - 주사위 눈은 숫자 단계에 맞춰 커지고(1~3 → 1~5 → 1~6), 4단계부터는 주사위 하나가 숫자로 나와 이어 세기를 연습합니다.
- 꾸미기 상점: 코인으로 옷, 모자, 소품, 방 배경을 사고 장착합니다.
- 오늘의 선물: 하루 한 번 코인을 받을 수 있습니다.

## 배우기를 돕는 장치

- 한 번 더 기회: 처음 틀리면 그 보기와 오답 하나를 지우고 힌트를 줍니다 (다시 들려주기, 같이 세기, 그림에 번호 붙이기, "1씩 커지고 있어" 등). 두 번째에 맞히면 코인 절반을 받습니다.
- 약한 것 다시 연습: 숫자와 글자마다 맞힌/틀린 기록을 남겨, 자주 틀리는 것이 더 자주 나옵니다.
- 도감: 숫자 1~20(10칸 틀, 같이 세기)과 자음·모음(이름, 예시 낱말, 가거고구기)을 눌러서 듣고 배웁니다. 잘 익힌 것은 스티커가 됩니다.
- 오늘의 미션: 매일 미션 3개를 다 하면 보물상자에서 코인 30개를 받습니다.
- 연속 정답: 처음에 맞힌 정답이 3번 이어질 때마다 보너스 코인을 받습니다.

## 단계

정답으로 별을 모으면 다음 단계가 열립니다. 열린 단계는 홈 화면에서 자유롭게 고를 수 있습니다.

| 단계 | 숫자 범위 | 바뀌는 점 |
| --- | --- | --- |
| 1 새싹 | 1~5 | 보기 4개 |
| 2 꽃잎 | 1~10 | 적은 쪽 고르기 추가 |
| 3 별빛 | 1~10 | 보기 6개, 빼기, 거꾸로 세기 |
| 4 무지개 | 1~15 | 카드 6쌍, 풍선이 더 빨라짐 |
| 5 왕관 | 1~20 | 2씩 뛰어 세기, 숫자 비교 |

한글 놀이도 따로 5단계가 있습니다: 자음 하나(ㄱ~ㅅ) → 자음 둘(14자) → 모음 → 글자 → 낱말.

## 목소리

설정(톱니바퀴)에서 기기에 있는 한국어 목소리를 골라 미리 들어볼 수 있고, 말 빠르기와 칭찬 목소리를 조절할 수 있습니다.
iPad에서는 `설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 한국어`에서 고품질 목소리를 내려받으면 훨씬 자연스러워집니다.

## 디자인 & 모션

- 숫자마다 고유 색상(1~10)을 정해 모든 게임에서 같은 색으로 보여줍니다.
- 둥근 한글 글꼴(Jua), 눌리는 입체 버튼, 떠다니는 숫자·구름 배경.
- 화면 전환, 카드 순차 등장, 숫자 타일 팝업, 메모리 카드 3D 뒤집기.
- 정답 시 색종이·별빛 축하 효과와 코인이 지갑으로 날아가는 애니메이션, 오답 시 흔들림과 정답 힌트.
- 몇 개일까: 그림을 눌러 "하나, 둘, 셋" 소리와 함께 직접 세어볼 수 있습니다.
- 효과음(Web Audio)과 켜기/끄기 버튼. 기기의 '동작 줄이기' 설정을 존중합니다.

## 실행

```bash
npm install
npm run dev
```

## 배포

이 저장소를 GitHub에 올린 뒤 Settings > Pages에서 Source를 `GitHub Actions`로 설정하세요.
`main` 브랜치에 push하면 `.github/workflows/deploy.yml`이 자동으로 빌드하고 GitHub Pages에 배포합니다.

## 그림 다시 만들기

`art/` 폴더에 일부 상점 소품, 방 배경, 별 그림, 숫자 찾기 아이콘의 벡터 원본이 있습니다.
수정한 뒤 Playwright가 있는 환경에서 `node art/render.mjs`를 실행하면 `public/assets`의 PNG가 다시 만들어집니다.
(특정 그림만: `node art/render.mjs magic-book room-moon`)
