# 숫자 놀이터

5살 아이가 iPad에서 숫자(1~20)와 한글을 놀이로 익힐 수 있도록 만든 React 학습 게임입니다.

## 기능

- 숫자 찾기: 음성을 듣고 맞는 숫자 카드를 선택합니다.
- 몇 개일까: 그림을 하나씩 눌러 세고 숫자를 고릅니다.
- 차례차례: 작은 숫자부터 순서대로 누릅니다.
- 카드 기억하기: 같은 숫자 카드 짝을 찾습니다.
- 어느 쪽이 많을까: 많은 쪽/적은 쪽(높은 단계에서는 큰 수/작은 수)을 고릅니다.
- 빈칸 채우기: 숫자 줄에서 빠진 숫자를 찾습니다. 거꾸로 세기, 2씩 뛰어 세기도 나옵니다.
- 더하기 빼기: 그림으로 덧셈과 뺄셈을 합니다.
- 풍선 터뜨리기: 날아오르는 풍선 중 목표 숫자를 찾아 터뜨립니다.
- 한글 놀이 (홈 화면 위쪽 탭에서 숫자/한글 전환)
  - 소리 듣고 찾기: 소리를 듣고 자음·모음·글자·낱말을 고릅니다.
  - 그림 글자: 그림을 보고 첫 자음, 첫 글자, 낱말을 찾습니다.
  - 글자 만들기: 자음과 모음을 합친 글자를 고릅니다 (ㄱ + ㅏ = 가).
  - 따라 쓰기: 손가락으로 글자를 따라 씁니다. 글자 선을 얼마나 따라갔는지 확인합니다.
- 주사위 마을 (홈 화면의 주사위 마을 배너): 부루마블처럼 2~4명이 한 기기로 함께 하는 보드게임. 화면 전체를 씁니다.
  - 사람마다 이름(나, 엄마, 아빠…)과 동물 말을 고르고, 자리를 "로봇"으로 바꾸면 혼자서도 할 수 있습니다.
  - 모두 10원으로 시작하고, 돈은 언제나 0~50원 사이입니다. 게임 길이는 5/10/15바퀴.
  - 주사위 점을 세어 답하면 그 수만큼 "하나, 둘, 셋" 세며 이동합니다. 똑같은 숫자가 나오면 한 번 더!
  - 빈 마을에서는 가진 돈으로만 집을 지을 수 있습니다(1~5원). 집값과 내 돈을 동전으로 나란히 보여주고 크기를 비교합니다.
  - 돈을 낼 때는 동전을 하나씩 눌러 세어서 냅니다. 내고 나면 "10 − 3 = 7"처럼 남은 돈을 보여줍니다.
  - 다른 사람 집에 서면 통행료(집값 × 층수)를 냅니다. 돈이 모자라면 집을 팔고, 그래도 모자라면 게임이 끝납니다.
  - 내 집에 다시 오면 2층 집 → 성으로 키우고(통행료가 커져요), 지붕 색과 꾸미기는 공짜로 바꿉니다.
  - 숫자 카드·글자 카드·학교 칸은 퀴즈(로봇 차례에는 로봇을 도와줘요), 저금통 칸은 2원을 모으고 보물 상자 칸에서 모인 돈을 가져갑니다. 꿀잠 섬에서는 한 번 쉽니다.
  - 마을 이름은 첫 글자와 자음을 알려줍니다(딸기는 ㄸ 쌍디귿으로 시작해요).
  - 끝나면 "누가 제일 많이 모았을까요?"를 먼저 맞혀 본 뒤 돈 + 집 값으로 순위를 보여주고, 상점 코인을 받습니다.
- 꾸미기 상점: 코인으로 옷, 모자, 소품, 방 배경을 사고 장착합니다.
- 오늘의 선물: 하루 한 번 코인을 받을 수 있습니다.

## 배우기를 돕는 장치

- 한 번 더 기회: 처음 틀리면 그 보기와 오답 하나를 지우고 힌트를 줍니다 (다시 들려주기, 같이 세기, 그림에 번호 붙이기, "1씩 커지고 있어" 등). 두 번째에 맞히면 코인 절반을 받습니다.
- 약한 것 다시 연습: 숫자와 글자마다 맞힌/틀린 기록을 남겨, 자주 틀리는 것이 더 자주 나옵니다.
- 도감: 숫자 1~20(10칸 틀, 같이 세기)과 자음·모음(이름, 예시 낱말, 가거고구기)을 눌러서 듣고 배웁니다. 잘 익힌 것은 스티커가 됩니다.
- 오늘의 미션: 매일 미션 3개를 다 하면 보물상자에서 코인 30개를 받습니다.
- 연속 정답: 처음에 맞힌 정답이 3번 이어질 때마다 보너스 코인을 받습니다.

## 부모님 기능

설정(톱니바퀴)은 곱셈 문제를 풀어야 열립니다(5분 동안은 다시 묻지 않음).

- 학습 리포트: 최근 7일 놀이 시간, 숫자·한글 정답률, 단계, 스티커, 자주 틀리는 숫자·글자, 1~20과 자음·모음별 익힘 정도.
- 쉬는 시간 알림: 15/20/30분 놀면 3분 쉬는 화면이 나옵니다. 기다리면 다시 놀 수 있고, 부모님은 곱셈 문제로 바로 풀어줄 수 있습니다.
- 놀이 시간은 화면을 보고 만지고 있을 때만 셉니다.

## 오프라인 · 홈 화면

한 번 열면 그림과 게임이 기기에 저장되어 인터넷 없이도 놀 수 있습니다.
iPad Safari에서 공유 → `홈 화면에 추가`를 하면 앱처럼 전체 화면으로 열립니다.

## 단계

정답으로 별을 모으면 다음 단계가 열립니다. 열린 단계는 홈 화면에서 자유롭게 고를 수 있습니다.

| 단계 | 숫자 범위 | 바뀌는 점 |
| --- | --- | --- |
| 1 새싹 | 1~5 | 보기 4개 |
| 2 꽃잎 | 1~10 | 적은 쪽 고르기 추가 |
| 3 별빛 | 1~10 | 보기 6개, 빼기, 거꾸로 세기 |
| 4 무지개 | 1~15 | 카드 6쌍, 풍선이 더 빨라짐 |
| 5 왕관 | 1~20 | 2씩 뛰어 세기, 숫자 비교 |

한글 놀이도 따로 5단계가 있습니다: 자음 하나(ㄱ~ㅅ) → 자음 둘(14자) → 모음 → 글자 → 낱말.

## 목소리

### 숫자 놀이터 목소리 (오픈소스, 모든 기기 공통)

앱이 말하는 모든 문장(약 1,600개)을 오픈소스 TTS인 [MeloTTS](https://github.com/myshell-ai/MeloTTS)(MIT 라이선스) 한국어 목소리로
미리 녹음해 `public/voice`에 mp3로 넣어 둘 수 있습니다. 녹음이 있으면 iPad, 안드로이드, PC 어디서나 같은 목소리로,
인터넷 없이도 말합니다. 녹음되지 않은 문장은 기기의 한국어 목소리로 읽습니다.

가장 쉬운 방법은 GitHub에서 **Actions → Generate voice pack → Run workflow**를 누르는 것입니다.
녹음이 끝나면 클립을 커밋하고 자동으로 다시 배포합니다(새 문장만 녹음, 전체 다시 녹음은 `force` 체크).

직접 녹음하려면 (Python 3.10 권장):

```bash
pip install -r scripts/voice/requirements.txt
python -m unidic download
node scripts/voice/build-catalog.mjs   # 앱이 말하는 문장 목록 → scripts/voice/phrases.json
python scripts/voice/generate.py       # 없는 클립만 녹음 → public/voice
```

녹음에는 pypi.org, download.pytorch.org, huggingface.co, myshell-public-repo-hosting.s3.amazonaws.com 접속이 필요합니다.
앱의 대사는 모두 `src/speech.js`에 모여 있어, 대사를 바꾼 뒤 위 과정을 다시 하면 새 문장만 녹음됩니다.

### 기기 목소리

설정에서 기기에 있는 한국어 목소리를 골라 미리 들어볼 수 있고, 말 빠르기와 칭찬 목소리를 조절할 수 있습니다.
iPad에서는 `설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 한국어`에서 고품질 목소리를 내려받으면 훨씬 자연스러워집니다.

## 디자인 & 모션

- 숫자마다 고유 색상(1~10)을 정해 모든 게임에서 같은 색으로 보여줍니다.
- 둥근 한글 글꼴(Jua), 눌리는 입체 버튼, 떠다니는 숫자·구름 배경.
- 화면 전환, 카드 순차 등장, 숫자 타일 팝업, 메모리 카드 3D 뒤집기.
- 정답 시 색종이·별빛 축하 효과와 코인이 지갑으로 날아가는 애니메이션, 오답 시 흔들림과 정답 힌트.
- 몇 개일까: 그림을 눌러 "하나, 둘, 셋" 소리와 함께 직접 세어볼 수 있습니다.
- 효과음(Web Audio)과 켜기/끄기 버튼. 기기의 '동작 줄이기' 설정을 존중합니다.

## 실행

```bash
npm install
npm run dev
```

## 배포

이 저장소를 GitHub에 올린 뒤 Settings > Pages에서 Source를 `GitHub Actions`로 설정하세요.
`main` 브랜치에 push하면 `.github/workflows/deploy.yml`이 자동으로 빌드하고 GitHub Pages에 배포합니다.

## 그림 다시 만들기

`art/` 폴더에 일부 상점 소품, 방 배경, 별 그림, 숫자 찾기 아이콘, 앱 아이콘의 벡터 원본이 있습니다.
수정한 뒤 Playwright가 있는 환경에서 `node art/render.mjs`를 실행하면 `public/assets`의 WebP 그림이 다시 만들어집니다.
(특정 그림만: `node art/render.mjs magic-book room-moon app-icon`)

새 PNG 그림을 넣을 때는 `python3 scripts/optimize-images.py public/assets/새그림.png`로 WebP로 바꾸고
코드의 경로를 `.webp`로 적어 주세요. 상점 그림은 512px로 줄여 로딩이 빨라집니다.
